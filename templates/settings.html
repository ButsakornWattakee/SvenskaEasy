⚙️ ตั้งค่าระบบเชื่อมต่อ AI (System Settings)

ตั้งค่าคีย์เชื่อมต่อปัญญาประดิษฐ์เพื่อรับประสบการณ์การตอบคำถามภาษาสวีเดนที่มีคุณภาพสูงสุด

🔑 ใส่ Google Gemini API Key

แนะนำให้ใส่คีย์ในไฟล์ .env เป็น GEMINI_API_KEY=... เพื่อให้ทุกคนในเว็บใช้ครู AI ได้ หรือใส่ชั่วคราวด้านล่างนี้ (เก็บเฉพาะในเซสชั่น)

📋 วิธีรับ Gemini API Key ฟรี:

  1. เข้าไปที่เว็บไซต์ Google AI Studio →
  2. เข้าสู่ระบบด้วยบัญชี Google
  3. คลิกปุ่ม Create API Key
  4. คัดลอกรหัสคีย์ (มักขึ้นต้นด้วย AIzaSy) นำมาใส่ช่องกรอกด้านบนและกดบันทึก
